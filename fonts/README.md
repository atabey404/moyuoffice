# 界面字体

`NotoSansSC.ttf` 来自 Google Fonts 的 Noto Sans SC 可变字体，用作聊天界面的无衬线字体，减少系统缺少中文界面字体时回退到宋体的差异。

- 来源：https://github.com/google/fonts/tree/main/ofl/notosanssc
- 原文件：`NotoSansSC[wght].ttf`（仅重命名，未修改字体数据）
- 下载日期：2026-11-04
- 许可：SIL Open Font License 1.1，全文见本目录 `OFL.txt`。

不同系统的字形栅格化与浏览器缩放仍可能有细微差异。

网页使用的 `NotoSansSC-Regular.woff2` 由上述可变字体固定到字重 400 后转换为 WOFF2（FontTools），以减小首次加载体积。原始 TTF 保留供核对与再生成。两份字体均沿用 SIL OFL 1.1。
