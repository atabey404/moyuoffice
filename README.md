# 摸鱼事务所 · Moyu Office

把工作间隙变成自己的学习时间。一个用熟悉的桌面聊天界面背单词的小工具。

**[在线体验](https://atabey404.github.io/moyuoffice/)**

## 可以做什么

- 微信风格浅色聊天界面，可设置联系人名称和头像。
- 学习模式：空回车获取下一个词；普通聊天不会推进学习进度。
- 回车翻译：外语单词 → 中文释义 → 下一个单词，支持英语、日语、韩语。
- 默写模式：只练习当前词库已经学过的单词，完成后可回车重复本轮。
- 生词本、CSV 词库导入、聊天记录和学习进度续接。
- GitHub 风格学习热力图、按日记录和词库进度。
- 单本词典的重新学习操作，需要二次确认。

## 数据与隐私

学习记录、聊天内容、头像和设置保存在访问者自己的浏览器中，不提供跨设备同步。清理浏览器网站数据会删除本机记录。其他访问者不会看到你的个人学习记录。

本工具是独立的聊天界面模拟，不连接微信、飞书或钉钉账号，与这些产品的权利人不存在隶属或官方合作关系。

## 运行

项目为原生 HTML / CSS / JavaScript 静态网站，不需要安装依赖或配置数据库。

下载仓库后可以直接打开 `index.html`；开发时也可用任意静态文件服务器运行。

## 发布到 GitHub Pages

1. 把本目录内容放入公开仓库的根目录。
2. 打开仓库 Settings → Pages。
3. Source 选择 Deploy from a branch，分支选择 main，目录选择 / (root)。
4. 等待部署完成，使用 GitHub 返回的网站地址。
