# MoyuOffice · 摸鱼事务所

[简体中文](../README.md) · [English](README.en.md) · **日本語** · [한국어](README.ko.md)

**いつものチャット画面で、すきま時間に単語を学習。**

[使ってみる](https://atabey404.github.io/moyuoffice/) · [不具合を報告](https://github.com/atabey404/moyuoffice/issues)

MoyuOffice は、WeChat 風のライト／ダーク表示のデスクトップ画面で英語・日本語・韓国語の単語を学べるウェブアプリです。短い休憩中に単語を確認し、学習した内容を少しずつ復習できます。

## 主な機能

- **学習モード**：単語と中国語訳を表示。元データにある発音表記や例文も表示します。
- **Enter で意味を確認**：入力欄が空のとき、Enter で外国語の単語、次の Enter で中国語訳、さらに Enter で次の単語を表示します。
- **書き取りモード**：中国語の意味を見て外国語の単語を入力。現在の単語帳で学習済みの単語だけが出題されます。空のまま Enter を押すとスキップして復習用ノートに保存し、一巡後は同じ範囲を繰り返せます。
- チャット履歴と単語帳ごとの進捗保存、復習用ノート、CSV 単語帳の読み込み、年間の学習ヒートマップ。
- 相手の名前・アイコンの変更と、正解時の控えめな通知のオン／オフ。

操作画面は現在、主に中国語です。この日本語紹介は、画面全体の日本語対応を意味するものではありません。英語は CET-4/6・IELTS・TOEFL など、日本語は JLPT N5〜N1・『標準日本語』のコミュニティ単語帳、韓国語は6段階の学習用単語リストを収録しています。公式試験の全出題語彙や、市販辞書の全文を保証するものではありません。

## はじめ方と保存について

サイトの「我的词典」で単語帳を選び、チャット画面の右上にある **•••** からモードや外観を選択します。外観の選択は現在のブラウザーに保存されます。Esc でホームに戻り、計時を終了します。時間は画面を開いている時間であり、集中して学習した時間を判定するものではありません。

履歴と設定は現在のブラウザーに保存されます。アカウント、クラウド同期、学習履歴の書き出し・読み込み機能はありません。端末・ブラウザー・サイトのアドレスを変更しても記録は自動移行されず、サイトデータを削除すると本機の記録も消えます。

実際のメッセージアカウントには接続しない独立したシミュレーターです。追加スキン、課金、AI 会話・自動採点、音声再生は現在提供していません。

## 実行・貢献

HTML・CSS・JavaScript による静的サイトです。リポジトリを取得して `index.html` を開くか、静的サーバーで配信できます。フロントエンドの依存関係をインストールする必要はありません。

詳細は [中国語ドキュメント](../README.md)、[貢献ガイド](../CONTRIBUTING.md)、[データの出典とライセンス](../dictionaries/SOURCES.md) をご覧ください。第三者データにはそれぞれのライセンスが適用されます。本プロジェクト独自のコードには、統一したオープンソースライセンスをまだ指定していません。



DingTalk のライトスキンも利用できます。WeChat スキンと学習進捗・学習モードを共有します。
