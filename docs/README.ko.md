# MoyuOffice · 摸鱼事务所

[简体中文](../README.md) · [English](README.en.md) · [日本語](README.ja.md) · **한국어**

**익숙한 채팅 화면에서, 자투리 시간을 어휘 학습으로.**

[바로 사용하기](https://atabey404.github.io/moyuoffice/) · [문제 제보](https://github.com/atabey404/moyuoffice/issues)

MoyuOffice는 밝은 WeChat 스타일의 데스크톱 화면에서 영어·일본어·한국어 어휘를 학습하는 웹 도구입니다. 짧은 휴식 시간에 단어를 확인하고, 이미 학습한 내용을 복습할 수 있습니다.

## 주요 기능

- **학습 모드**: 단어와 중국어 뜻을 보여 주며, 원본 자료에 있는 경우 발음 표기와 예문도 표시합니다.
- **Enter로 뜻 확인**: 입력창이 비어 있을 때 Enter를 누르면 외국어 단어, 다시 누르면 중국어 뜻, 그다음에는 다음 단어를 표시합니다.
- **받아쓰기 모드**: 중국어 뜻을 보고 외국어 단어를 입력합니다. 현재 단어장에서 학습한 단어만 출제됩니다. 빈 입력 상태에서 Enter를 누르면 건너뛰고 복습 노트에 저장하며, 한 회차를 마치면 같은 범위를 반복할 수 있습니다.
- 대화 기록과 단어장별 진도 저장, 복습 노트, CSV 단어장 가져오기, 연간 학습 히트맵.
- 대화 상대 이름·프로필 이미지 변경, 정답 알림 켜기·끄기.

현재 앱 화면은 주로 중국어로 제공됩니다. 한국어 소개 문서는 앱 전체의 한국어 지원을 의미하지 않습니다. 영어는 CET-4/6·IELTS·TOEFL 등을, 일본어는 JLPT N5–N1과 『표준일본어』 커뮤니티 단어장을, 한국어는 6단계 학습 참고 어휘 목록을 제공합니다. 공식 시험의 모든 어휘나 상업용 사전 전문을 제공하는 것은 아닙니다.

## 시작하기와 데이터 저장

사이트의 **我的词典**에서 단어장을 선택한 후 채팅 화면으로 들어가 모드를 고르세요. Esc를 누르면 홈으로 돌아가며 사용 시간 측정이 끝납니다. 측정 시간은 스킨을 열어 둔 시간이며, 실제 집중 학습 시간을 판정하지 않습니다.

기록과 설정은 현재 브라우저에 저장됩니다. 계정, 클라우드 동기화, 학습 기록 내보내기·가져오기는 제공하지 않습니다. 기기·브라우저·사이트 주소를 바꾸면 기록이 자동으로 이전되지 않으며, 사이트 데이터를 지우면 로컬 기록도 삭제됩니다.

실제 메신저 계정에 연결하지 않는 독립적인 시뮬레이터입니다. 다크 모드, 추가 스킨, 결제, AI 대화·채점, 음성 재생은 현재 지원하지 않습니다.

## 실행 및 기여

HTML·CSS·JavaScript로 만든 정적 사이트입니다. 저장소를 내려받아 `index.html`을 열거나 정적 서버로 실행할 수 있습니다. 프런트엔드 의존성 설치는 필요하지 않습니다.

자세한 사용법과 CSV 형식은 [중국어 문서](../README.md), [기여 안내](../CONTRIBUTING.md), [데이터 출처와 라이선스](../dictionaries/SOURCES.md)를 참고하세요. 외부 데이터에는 각각의 라이선스가 적용됩니다. 프로젝트 자체 코드의 통일된 오픈소스 라이선스는 아직 지정되지 않았습니다.
